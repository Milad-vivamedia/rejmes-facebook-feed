📋 SETUP CHECKLIST (10 minutes)

□ 1. CREATE GITHUB REPO
     • Name: rejmes-facebook-feed
     • Public repository
     • https://github.com/new

□ 2. PUSH FILES
     From rejmes-setup folder:

     git init
     git add .
     git commit -m "Initial commit - Rejmes Bil Facebook feed"
     git remote add origin https://github.com/YOUR-USERNAME/rejmes-facebook-feed.git
     git branch -M main
     git push -u origin main

□ 3. ENABLE ACTIONS
     Settings → Actions → General:
     ✓ Allow all actions
     ✓ Read and write permissions
     ✓ Save

□ 4. RUN FIRST WORKFLOW
     Actions → Update Facebook Feed → Run workflow
     (Wait for green checkmark ✓)

□ 5. ENABLE GITHUB PAGES
     Settings → Pages:
     • Branch: gh-pages
     • Folder: / (root)
     • Save
     (Wait 2 minutes)

□ 6. GET YOUR FEED URL
     https://YOUR-USERNAME.github.io/rejmes-facebook-feed/feed.xml

□ 7. ADD TO FACEBOOK
     Facebook Commerce Manager → Catalog → Data Feeds:
     • Add Items → Use Data Feeds
     • Scheduled fetch
     • Enter feed URL
     • Update: Hourly
     • Start Upload

✅ DONE! Feed updates automatically every hour.
